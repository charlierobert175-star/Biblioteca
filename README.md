# Biblioteca

Biblioteca digital com acesso reservado a leitores registados.
Organizada por Charles Alberto Araújo, Maputo.

- Site: GitHub Pages (index.html na raiz).
- Login, lista de leitores e PDFs: Supabase (projecto "biblioteca").
- Os PDFs ficam na pasta privada `livros` do Supabase; só leitores registados os conseguem abrir.
- `supabase/setup.sql`: tabelas, funções e regras de acesso (já aplicado).
- `livros.json`: catálogo; `capas/`: imagens das capas.
